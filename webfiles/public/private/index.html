Worth knowing

  • One shared password for the whole class, so treat anything here as semi-public.
  • Basic auth has no logout. Closing the browser clears the cached credentials.
  • The protection is the /private/ path prefix in the nginx vhost, not this file. A page moved out of this directory is public again.
  • The /users API stays open — only pages under this prefix are restricted.
